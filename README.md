End-to-end Azure Data Warehouse implementation using Azure Synapse Analytics, Azure Data Factory, PySpark, and SQL. This project demonstrates building a modern cloud data warehouse solution including ETL pipelines, incremental data loading, data transformation, external tables, dimensional modeling, and Slowly Changing Dimensions (SCD).

The project covers the complete data engineering workflow:

Designing a cloud-based data warehouse architecture using Azure services
Building ETL pipelines using Azure Data Factory
Implementing incremental data loading strategies
Performing data transformations using PySpark
Creating external data sources and external tables in Azure Synapse Analytics
Applying schema handling techniques
Designing dimensional data models
Implementing Star Schema and Snowflake Schema
Creating Fact and Dimension tables
Implementing Slowly Changing Dimensions (SCD Type 1 & Type 2)
Building an end-to-end Azure Data Engineering pipeline

Technologies Used:

Microsoft Azure
Azure Synapse Analytics
Azure Data Factory
Azure Data Lake Storage Gen2
PySpark
SQL
CETAS (Create External Table As Select)
Dimensional Data Modeling
Star Schema
Snowflake Schema
Slowly Changing Dimensions
